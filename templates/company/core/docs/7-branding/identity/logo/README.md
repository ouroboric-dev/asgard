# Logo

<!-- Asgard: filled at step 6 (Brand: look). Answers readiness RB-21. Delete this comment when the section is written. -->

The founder brings the logo as a PNG made outside Asgard (flat colours on a transparent background, high
resolution). It is traced into SVG, recoloured with the palette for the light and dark versions, and exported as a
favicon and app icons. Only the final files are committed here; raw sources stay out of the repository.

| File | Use |
| --- | --- |
| `logo.svg`, `logo-dark.svg` | the logo on light and dark backgrounds |
| `favicon.svg`, `favicon.ico` | the browser tab |
| `icon-192.png`, `icon-512.png` | app icons |
