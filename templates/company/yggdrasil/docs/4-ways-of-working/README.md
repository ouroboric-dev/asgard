- [Docs standard](https://github.com/ouroboric-dev/ouroboric/blob/main/docs/4-ways-of-working/docs-standard.md):
  where each document lives and its front matter.

  and [diagrams](https://github.com/ouroboric-dev/ouroboric/blob/main/docs/4-ways-of-working/diagrams.md).
